# Dashboard de Vendas e Devoluções

Projeto de Business Intelligence desenvolvido no Power BI para acompanhar o desempenho comercial de uma rede de lojas. O dashboard reúne análises de vendas, faturamento e devoluções, permitindo explorar os resultados por mês, produto, loja e ano.

A solução apresenta indicadores como total vendido, quantidade devolvida, produtos mais e menos vendidos, produtos com maior índice de devolução e desempenho de cada loja. O objetivo é transformar dados brutos em informações visuais e úteis para apoiar decisões comerciais e identificar oportunidades de melhoria.
